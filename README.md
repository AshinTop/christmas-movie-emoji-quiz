# Christmas Movie Emoji Quiz | Play a Christmas Movie Guessing Game

**[Play Christmas Movie Emoji Quiz on Crazy3D](https://crazy3d.org/christmas-movie-emoji)** · [中文介绍](#中文介绍) · [Christmas Pictionary](https://crazy3d.org/christmas-pictionary)

Turn a row of emojis into a movie title before the five-minute clock runs out. **Christmas Movie Emoji Quiz** is a browser-based holiday trivia game with English and Chinese interfaces, a shuffled movie question bank, and a leaderboard saved on the current browser.

A house, a surprised face, a boy and a Christmas tree might suggest *Home Alone*. Other clues draw on Christmas films and winter holiday viewing, so both familiar favorites and less obvious titles appear. Play a solo round, take turns on one device, or let a group suggest answers while one person types.

## How to play

1. Open the [Crazy3D game page](https://crazy3d.org/christmas-movie-emoji), choose English or Chinese, and enter a nickname.
2. Read the emoji clue, type a movie title, then press Enter or select Submit.
3. Each correct answer earns **one point**. An incorrect answer earns no point and briefly reveals the answer before advancing.
4. Use Skip when a clue has you stuck. The shared **300-second timer** keeps running through the round.
5. At the end, compare your score with the local leaderboard, save a result image, or start another round.

The game compares your answer with each question's accepted titles after ignoring letter case, spaces and punctuation. This is **not** unrestricted AI or typo-tolerant matching: a different spelling or an unlisted translation may be rejected.

## Features

- **Five-minute movie quiz:** one timer for the whole round, rather than a separate countdown for each question.
- **Built-in question bank:** 105 entries in the current source, shuffled for each new game; questions are loaded locally rather than generated by a live AI request.
- **English and Chinese interface:** switch the interface language and use the accepted English or Chinese answers provided by each question.
- **Local high scores:** the browser stores the best score for each nickname. This is not a worldwide leaderboard or cross-device account.
- **Result cards:** image download through `html2canvas`, plus sharing or clipboard controls where supported by the browser.
- **Festive feedback:** Christmas colors and confetti celebrate correct answers.

## Tips for a holiday game night

Think about characters and memorable scenes, not just literal objects. A short clue may describe the film's setting rather than its title. If the group is taking turns, use different nicknames and the same browser so everyone can compare local scores.

For remote gatherings, screen sharing can let other people watch and suggest answers. The game itself does not create online rooms or synchronize separate devices. Some movie choices and answers may be unfamiliar to younger players; an adult can help choose an appropriate way to play.

## Frequently asked questions

### Is this a multiple-choice quiz?
No. You type the film title. Each question contains a defined list of accepted answers.

### Why did my score disappear?
Scores are kept in `localStorage` for the current browser and game origin. Clearing site data, switching browser or opening a different deployment can give you a different leaderboard.

### Can I download my result?
The result screen includes Save Image. Download and native sharing behavior depend on your browser; a regular screenshot is an alternative.

### Is an AI API key required for the quiz?
The current quiz flow uses `services/questionBank.ts`. Despite its filename, `services/geminiService.ts` only shuffles the local bank. Do not add a private API key to a public frontend build.

## Development

The project uses **React 19, TypeScript 5.8 and Vite 6**, with Tailwind utility styling, React Context for language selection, `canvas-confetti` and `html2canvas`.

```bash
git clone https://github.com/AshinTop/christmas-movie-emoji-quiz.git
cd christmas-movie-emoji-quiz
npm install
npm run dev
```

The development server is configured for port 3000; use the address printed by Vite. To create and inspect a production build:

```bash
npm run build
npm run preview
```

Vite outputs the build to `dist/`. Important files:

- `App.tsx`: round state, timer and scoring.
- `components/GameScreen.tsx`: answer input, matching and feedback.
- `services/questionBank.ts`: movie clues and accepted answers.
- `services/leaderboardService.ts`: local high scores.
- `contexts/LanguageContext.tsx` and `services/translations.ts`: interface translations.

Contributions are welcome. For a new question, provide clear emojis, accurate English/Chinese titles and useful accepted answers; check that the clue does not duplicate an existing entry.
