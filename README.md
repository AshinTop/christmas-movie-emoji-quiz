## 📖 Introduction (简介)

**Christmas Movie Emoji Quiz** is a fast-paced, festive time-attack web game designed for movie lovers and holiday enthusiasts.

Can you guess the classic Christmas movie title based on a string of emojis? From *Home Alone* 😱 to *Die Hard* 👮‍♂️, test your knowledge against the clock! Perfect for **Zoom parties**, **office icebreakers**, or a cozy **family game night**.

**圣诞电影表情符号猜猜猜** 是一款专为影迷设计的节日挑战游戏。你需要在限定时间内，通过一组 Emoji 表情线索猜出经典的圣诞电影。无论是《小鬼当家》还是《真爱至上》，这都是**远程聚会**、**公司团建**或**家庭游戏之夜**的完美破冰神器！

## ✨ Key Features (核心特色)

*   **⏱️ 5-Minute Time Attack:** Race against the global timer to score as many points as possible.
    *   **5分钟极速挑战：** 与时间赛跑，测试你的反应速度。
*   **🎬 Huge Movie Database:** Featuring 100+ classics including *Harry Potter*, *Love Actually*, *Elf*, and Netflix hits.
    *   **海量题库：** 收录100+部经典影片，从黑白老片到Netflix最新热剧。
*   **🌍 Bilingual Support:** Fully localized in English and Chinese with fuzzy matching for answers.
    *   **中英双语：** 支持中英文界面及答案输入，智能模糊匹配。
*   **🏆 Local Leaderboard:** Challenge your friends on the same device and save high scores locally.
    *   **本地排行榜：** 聚会神器，支持多人轮流挑战并记录最高分。
*   **📸 Shareable Results:** Generate a beautiful image card of your score or leaderboard to share on social media.
    *   **战绩分享：** 一键生成精美的成绩单或排行榜图片，分享至朋友圈/Instagram。
*   **🎨 Festive UI/UX:** Built with React 19 & Tailwind CSS, featuring snow effects, confetti, and smooth animations.
    *   **精致交互：** 沉浸式圣诞氛围，下雪特效、礼花动画，体验极佳。

## 🎮 How to Play (如何玩)

1.  **Enter Name:** Type your nickname to start.
2.  **Guess:** Look at the emojis (e.g., 🏠😱👦) and type the movie title (e.g., "Home Alone").
3.  **Score:** Get points for correct answers. Speed matters!
4.  **Win:** Check your rank on the leaderboard and share your victory!

1.  **输入昵称：** 输入你的大名开始游戏。
2.  **猜题：** 观察屏幕上的 Emoji（如 🏠😱👦），输入电影名称（如“小鬼当家”）。
3.  **得分：** 答对得分，答错不扣分但浪费时间。
4.  **分享：** 查看本地排名，生成图片分享你的“影迷等级”。

## 🛠️ Tech Stack (技术栈)

*   **Frontend:** React 19, TypeScript
*   **Styling:** Tailwind CSS, Custom Animations
*   **State Management:** React Context API (Language/Theme)
*   **Persistence:** LocalStorage (for Leaderboards)
*   **Utilities:**
    *   `canvas-confetti`: Celebration effects
    *   `html2canvas`: Screenshot generation for sharing

## 🚀 Development (本地运行)

To run this project locally:

1.  **Clone the repo**
    ```bash
    git clone https://github.com/AshinTop/christmas-movie-emoji-quiz.git
    cd christmas-movie-emoji-quiz
    ```

2.  **Install dependencies**
    ```bash
    npm install
    ```

3.  **Run the development server**
    ```bash
    npm run dev
    ```

4.  Open `http://localhost:3000` in your browser.
